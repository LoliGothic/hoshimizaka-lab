# 星見坂天文同好会 調査ファイル

星見坂（ほしみざか）天文同好会の管理人・ミナトさんから、調査の依頼が届きました。
「最近サイトの様子がおかしい。メンバーのハルカさんとも連絡が取れない」——
あなたは調査員として、同好会の Web サイトを調べ、何が起きたのかを突き止めてください。

## 準備

[Docker Desktop](https://www.docker.com/products/docker-desktop/) を入れて、起動しておきます。

- Windows の方は、インストール時に WSL2 が有効になります（基本はそのままでOK）。
- 起動後、メニューバー／タスクトレイのクジラのアイコンが「Running」になっていれば準備完了です。

## 始め方

このフォルダ（`compose.yaml` のある場所）で、次のコマンドを実行します。

```sh
docker compose up -d
```

初回はイメージのダウンロードで少し待ちます。終わったら、ブラウザで次を開きます。

```
http://localhost:5173/
```

## 遊び方

1. ミナトさんからの依頼メールを読んで「調査を始める」を押します。
2. 右下の「**調査ノート**」に、ミナトさんからの問いが書いてあります。
   サイトを調べて手がかりを見つけ、問いに答えると、次の章に進めます。
3. 行き詰まったら、調査ノートのヒントを使ってください。

## ルール

- 使ってよいのは、**ブラウザと開発者ツール（F12）だけ**です。
- コンテナやサーバーのプログラムの中身は「サーバーの中」という設定なので、**調査対象外**です。
- 入会フォームなどには、**本当の個人情報を入力しないでください**。
- ここで学ぶ技術を、**許可のない他人のサイトで試すと、不正アクセス禁止法違反などの犯罪**になります。

## 終わるとき

```sh
docker compose down -v
```

調査の記録も消えます。記録を残したいときは `-v` を外してください。

## うまく動かないとき

- **ポートが使用中**というエラー：ほかのアプリが 5173／5174 を使っています。そのアプリを閉じるか、
  時間をおいて再度 `docker compose up -d`。
- **画面が出ない／古い**：`docker compose pull` で最新を取り直してから `docker compose up -d`。
- **最初からやり直したい**：調査ノートの「最初からやり直す」、または `docker compose down -v` のあと
  もう一度 `docker compose up -d`。
